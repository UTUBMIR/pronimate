### Animate and explain you ideas using only one short prompt and let the agent do the rest for you.

## Flow:
1. generate the animation plan:
   * Point you agent at the [PLAN.md](PLAN.md)
   * Tell your agent a topic and additional details to make the explanation/animation about
   * Press enter
2. Then just tell the agent to implement the plan
3. Verify your animation and possibly tell the agent to make changes to it
4. Render your final result in high-quality-mode
