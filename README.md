### Animate and explain you ideas using only one short prompt and let the agent do the rest for you.

## Flow:
* generate the animation plan:
  1. Point you agent at the [PLAN.md](PLAN.md)
  2. Tell your agent a topic and additional details to make the explanation/animation about
  3. Press enter
* Then just tell the agent to implement the plan
* Verify your animation and possibly tell the agent to make changes to it
* Render your final result in high-quality-mode
